# PokéExplorer

Aplicación web móvil tipo Pokédex desarrollada para el integrador de Aplicaciones Móviles.

## Tecnologías
- HTML5
- CSS3
- JavaScript ES6+
- Fetch API
- localStorage
- Hash routing

## Vistas
- Home
- Búsqueda
- Detalle
- Lista de deseos
- Historial
- Contacto

## Ejecución
Abrir `index.html` con Live Server o desde un servidor local para evitar problemas con módulos ES.
